My Projects

MESS MARKING WEB APP

Completed

Next.js Firebase Firestore Vite

Developed a progressive web application for hostel students to mark daily meal preferences (B/L/S) digitally, replacing manual registers.

Implemented Firebase Authentication for secure student login, Firestore for real-time meal marking and analytics, and automated CI/CD through GitHub Actions.

Optimized the system for offline access, push notifications, and installable PWA support to ensure seamless use even during network interruptions, improving mess workflow efficiency.

The project significantly reduced hostel food waste and is highly relevant to society.
