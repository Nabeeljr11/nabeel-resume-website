01 PWA · Completed Mess Marking Replace the register.

Completed

Mess Marking Web App

A progressive web application for hostel students to mark daily meal preferences (B/L/S) digitally, replacing manual registers.

Firebase Authentication handles secure student login. Firestore stores real-time meal marking and analytics. GitHub Actions automates CI/CD. The app is optimized for offline access, push notifications, and installable PWA support so it still works during network interruptions.

The system improved mess workflow efficiency and reduced hostel food waste — a digital solution with a direct social impact.

  • Next.js
  • Firebase
  • Firestore
  • Vite
